Unit 1.5: Forces

1.5: Forces -

Force: A push or pull that acts on an object which can 
alter the object’s speed, direction and shape. It is a 
vector quantity, since it has both magnitude and
direction.

Effect of force -

Speed: Cause objects to speed up or slow down
Direction: Change the direction of an object’s travel
Shape: Cause objects to stretch, compress or deform

Extension in springs -

Extension is proportional to stretching force.

Example: If a spring extends 1cm when a stretching 
force of 1N is applied, the spring      
will extend 2cm if a stretching force of 2N is applied.

This rule is only true if the limit of proportionality of the spring is not exceeded.

Limit of proportionality: The point at which the load-extension graph becomes
                                          non-linear, because the extension is no longer proportional
                                          to the stretching force.

Spring constant (K) -

Defined as force per unit extension, it is the force which must be applied to cause an extension of 1m to a spring.

Formula: Spring constant (K, in N/m) = Force (F, in N) ÷ Extension (x, in meters.)

Forces and resultants -

In a diagram, forces are shown by a straight line with an arrow to show direction. The line’s length represents the amount of force.

If an object is resting on a table, its weight is shown by an arrow pointing down, and its contact force force due to the table supporting it is shown by an arrow pointing up. These arrows are the same in length and opposite in direction, which means the forces are balanced, the resultant force is 0.
